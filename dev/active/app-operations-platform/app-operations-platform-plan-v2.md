# 앱 운영 자동화 개발계획 v2 — 빌드 자격 증명·SNS/커뮤니티 확장

고정일: 2026-09-11. 상태: 유효 개발 기준선. 사용자의 추가 구현 지시를 반영한 버전이다.

이 계획은 [v1](app-operations-platform-plan.md)의 R-01~10, V-01~10, Phase 1~9와 완료 조건을 전부 승계한다. v1 원문과 SHA-256은 보존한다. 아래 두 영역을 추가하며 기존 스토어·엔진·마케팅·수익화 범위를 축소하지 않는다. 진행 상태는 [tasks](app-operations-platform-tasks.md), 실측 근거와 재개 정보는 [context](app-operations-platform-context.md)에 기록한다.

## R-11 — 빌드 키를 한 번 등록하고 재사용

Git/서버 접근용 SSH 개인 키와 Android 서명용 키스토어를 구분한다. 사용자는 파일과 필요한 암호를 한 번 등록하고 프로젝트에 연결한다. 이후 해당 프로젝트의 검수·의존성 준비·빌드·서명은 저장된 연결을 사용한다. Android의 키 별칭·인증서 지문, SSH 공개 키·서버 호스트 키, 버전·교체·사용 프로젝트를 관리한다.

비밀은 기존 OS 보관함과 암호화 vault에 저장한다. DB·UI 응답·이력에는 공개 메타데이터와 참조만 기록한다. 서명 키는 프로젝트가 실행하는 빌드 스크립트에 제공하지 않는다. 신뢰된 의존성 가져오기와 빌드 후 서명 단계가 필요한 시간에만 제한된 임시 파일로 사용하고 제거한다. SSH 서버 키를 고정하며 임의 호스트나 프록시로 전달하지 않는다. 회전 중 진행 중인 작업은 선택 당시 키 버전을 사용한다. 사용 중인 키 삭제는 원인을 표시하며 차단한다.

iOS 인증서·프로비저닝은 v1의 필수 범위로 유지한다. Linux에서 검증한 Android/SSH 구현을 macOS/iOS 서명 검증으로 표시하지 않는다. 지원 OS와 실제 설치된 서명 도구별 검증은 별도로 기록한다.

## R-12 — SNS·커뮤니티 운영 자동화

X, Threads, Steam을 앱 운영 채널로 연결한다. 계정 최초 연결, 게시물/공지 작성, 예약 발행, 출시 연계 공지, 반응·댓글/답글 수집, 설정한 답변 규칙, 실행·실패·복구 이력을 제공한다. 같은 프로젝트의 채널을 묶어 운영하고 채널별 게시 결과를 개별 추적한다.

사용자는 처음 저장한 정책으로 채널, 예약, 자동 게시·답변 범위와 빈도 한도를 정한다. 정책 안의 실행에서 반복 로그인이나 매번 승인 요청을 추가하지 않는다. 공식 갱신 토큰 등으로 연결을 유지하며 권한 철회처럼 갱신으로 해결되지 않는 경우에만 필요한 조치를 표시한다. 앱에 대한 기존 구현 승인은 검증 과정에서 임의 계정 게시나 메시지 전송을 수행하라는 의미로 확대하지 않는다.

외부 게시 전 의도를 기록하고 원격 게시 ID·Threads 컨테이너 등 복구 단서를 저장한다. 결과가 불명확하면 재게시하지 않고 조회로 조정한다. 계정 간·프로젝트 간 답글 대상을 검증한다. 외부 댓글을 실행 명령이나 운영 정책으로 취급하지 않는다. 삭제·차단 등 복구하기 어려운 조정은 별도 명시 정책이 있는 지원 기능만 제공한다.

공식 API에서 제공하지 않는 동작은 성공으로 표시하지 않는다. 특히 Steam 뉴스 읽기와 커뮤니티 공지 게시·댓글 관리의 실제 제공 범위를 구분한다. 공식 쓰기 API가 없는 영역은 필요한 웹 작업과 저장된 세션의 재사용 가능성을 별도 검증하고, 그 어댑터를 구현·검증하기 전까지 지원 범위에 포함하지 않는다. 소셜 지표는 노출·반응·답글 등 원천 정의를 보존하며 매출 또는 광고 ROAS로 변환하지 않는다.

## 추가 단계와 수용 기준

| 단계 | 작업 | 수용 기준 |
|---|---|---|
| Phase 10 | 키 등록·회전·프로젝트 연결 | 암호문 저장, 공개 메타데이터만 반환, 잘못된 키·암호 거부, 사용 중 삭제 차단 |
| Phase 10 | SSH 의존성·Android 서명 | 고정한 서버만 접근, 빌드 스크립트에서 비밀 접근 불가, 버전 고정, 실제 서명·인증서 검증 |
| Phase 10 | UI·복구·검증 | 한 번 등록 후 재사용, 실패/취소 임시 파일 제거, 비밀 유출·키 교체 회귀 검사 |
| Phase 11 | 소셜 인증·채널 어댑터 | 공급자별 API 계약, 갱신·회전, 계정 소유권, Steam 지원 한계 명시 |
| Phase 11 | 예약·출시 공지·중복 방지 | 재시작 후 예약 유지, 정책 변경 반영, 채널별 결과, 응답 유실 시 중복 게시 방지 |
| Phase 11 | 커뮤니티·정책·화면 | 댓글/반응 조회, 프로젝트 연결, 제한된 답변 규칙, 빈도 한도, 실제 오류/대기 표시 |
| Phase 11 | 통합·실계정 검증 | 모의 API 장애 검사와 실제 연결/게시 검증을 구분하고 지원표·운영 문서에 근거 기록 |

V-11은 SSH·서명 키의 전체 수명주기와 실제 격리 도구 실행, V-12는 소셜 인증·예약·발행·응답 유실·정책 경계 검증이다. 실계정·macOS 장비·엔진 라이선스·장기 관찰이 필요한 기존 미완료 조건은 그대로 남는다. 전체 개발 완료는 문서·코드 생성이나 모의 API 검사만으로 선언하지 않는다.

이 버전의 후속 요구 변경은 다음 plan 버전에 기록한다. 11개 Phase, 37개 작업을 [작업 목록](app-operations-platform-tasks.md)에서 추적한다.
