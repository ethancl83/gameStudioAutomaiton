# 앱 운영 플랫폼 개발계획 v5 — 실사용 점검 후속 수정

고정일: 2026-09-12. 사용자 지시: 계정 연결을 전제로 실사용 문제를 확인하고, 보고한 내용을 수정한다. 게임 빌드는 외부에서 수행한다. v4와 이전 계획은 보존한다.

## 이번 완료 조건

1. 외부 쓰기의 명확한 거절과 결과 불명을 구분한다. 불명 결과에는 서비스 확인 후 수동 결론 기록을 제공하며 자동 재전송하지 않는다.
2. 하나의 스토어 연결에 속한 모든 등록 앱을 개별 동기화하고 수동 조회에서 프로젝트를 선택한다.
3. 광고 캠페인 전체 조회가 성공하면 삭제된 캠페인을 캐시와 예산 계산에서 제거한다. 일부 조회·실패에서는 보존한다.
4. 출시 공지는 관측된 실제 공개 전환을 사용한다. 초기 과거 버전·업로드 접수만으로 공지하지 않는다.
5. 외부 Android/iOS 파일·Steam 콘텐츠 폴더를 복사·검사·보관하고 프로젝트에 귀속한다. 엔진·SDK 설치나 내부 빌드 없이 가져온 결과물로 업로드한다. 업로드 직전 무결성을 재확인한다.
6. Apple 이미지 검사의 비동기 계약과 실제 이미지 fixture를 수정한다.

## 검증과 기록

root가 순차 구현한다. 각 오류의 재현 조건, 실패·재시작·앱/계정 경계, 외부 파일 손상/변조·다른 앱 차단을 회귀 검사한다. 타입 검사·전체 자동 검사·운영 앱 컴파일과 실행 화면의 외부 결과물 흐름을 확인한다. 실제 스토어 반영·실계정 권한은 모의 검증과 구별한다. 이전 장비/장기 운영 수용 조건을 이번에 달성한 것으로 표시하지 않는다.
