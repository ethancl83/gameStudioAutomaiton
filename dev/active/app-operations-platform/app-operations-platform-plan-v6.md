# 앱 운영 플랫폼 개발계획 v6 — 프로젝트 등록으로 시작하는 AI 운영

고정일: 2026-09-13. v1–v5는 보존한다.

## 사용자 요구

프로젝트 폴더를 한 번 등록하면 AI가 내용을 분석하고 스토어 문구·이미지를 준비하며 계정 연결·스토어 등록을 진행한다. 로그인·본인 확인·프로젝트로 판단할 수 없는 필수 정보만 요청하고 답변 후 이어간다. AI 실행기는 설치된 Codex / OpenCode CLI이며 기존 인증·모델 설정을 재사용한다. 앱은 기존 Electron 구조를 사용한다. 게임 빌드는 외부에서 한다.

## 실행 계약

- 등록 시 프로젝트별 내구성 있는 AI 작업을 자동 생성한다. CLI 자동 탐지, 선택, 진행·대기·실패·중지·재개를 제공한다. CLI 부재나 로그인 실패를 성공으로 숨기지 않는다.
- 원본을 수정하지 않고 제한된 프로젝트 자료를 작업 공간에 준비한다. 비밀 파일·보관함은 분석 자료에 포함하지 않는다. 작업 공간과 진행 기록을 재사용한다.
- 두 CLI에 같은 프로젝트 전용 MCP 도구를 제공한다. 저장된 계정·프로젝트 정보·실행 이력·이미지·스토어 API를 재사용한다. 프로젝트 밖 변경·광고 집행·공개/심사 제출은 자동 등록 범위에 포함하지 않는다.
- AI가 만든 실제 문구와 이미지 파일을 저장하고 화면에서 검토한다. 기존 이미지와 생성한 홍보 그림의 출처를 구분한다. 생성한 그림을 게임 플레이 스크린샷으로 표시하지 않는다.
- API가 신규 앱 생성을 제공하지 않는 공급자는 CLI에 설정된 브라우저 도구로 공식 콘솔 절차를 수행한다. 해당 도구 부재·로그인·계약·판단 불가능한 필수 질문은 정확한 대기 사유로 남긴다. 준비 결과를 실제 등록 성공으로 취급하지 않는다.
- 외부 작업은 기존 큐·정책·중복 방지·결과 불명 계약을 사용한다. 중단 후 결과를 먼저 확인하며 동일 의도를 중복 전송하지 않는다. 완료에는 실제 작업 근거가 필요하다.
- 데모는 실계정·실제 CLI 호출과 분리한다. 실서비스 게시·장비별 검증은 모의 검사와 구별한다.

## 완료 조건과 검증

1. 두 CLI의 비대화형 실행·MCP 연결·종료/취소·오류 처리 및 자동 탐지를 검사한다.
2. 실제 HTTP/MCP 경계와 임시 DB로 등록→자료 생성→스토어 작업→대기/재개를 검사한다. 비밀 배제·작업/계정 범위·중복·재시작·허위 완료 차단을 포함한다.
3. UI에서 자동 시작, CLI 선택, 문구/이미지 결과와 최소 조치 입력을 확인한다.
4. 타입·전체 자동 검사·빌드 및 관련 브라우저 검증을 수행하고 tasks/context/검증 기록을 갱신한다.
