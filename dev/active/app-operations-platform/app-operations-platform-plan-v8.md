# 앱 운영 플랫폼 개발계획 v8 — 버튼의 임의 실행 제거

고정일: 2026-09-13. 사용자가 AI 요청 버튼의 임의 실행과 원하지 않는 요청 내용을 지적하고, 요청 흐름은 직접 재설계하겠다고 확정했다. 이번 변경은 기존 동작의 자동 전송 제거에 한정한다. v1–v7은 이력으로 보존한다.

- AI 요청 버튼은 현재 화면과 선택 대상을 전달해 기존 채팅만 연다. 클릭만으로 실행하거나 사용자 발언을 저장하지 않는다.
- 화면별 고정 작업 지시를 제거한다. 전송 버튼 또는 Enter로 사용자가 보낸 문장만 요청으로 취급한다. 서버에서도 내용 없는 요청을 거부한다.
- 새 작업 후보·제안 선택·승인 단계 등 요청 흐름은 추가하지 않는다. 재설계는 사용자에게 맡긴다.
- 질문·분석을 계정 설정·등록 지시로 확대하지 않도록 CLI 지시를 정정한다. 요청 시점의 화면·선택 범위와 기존 resume/clear 계약을 유지한다.
- 기존 모드 전환 수정도 커밋한다. 2차 성장 운영은 계속 기획만 유지한다.

완료 조건: 빈 요청의 HTTP 거부와 실행 0건, 명시한 문장·선택 범위·동일 세션 전달, 모든 화면의 버튼 열기/닫기 무실행, Electron 전송·resume·clear, 타입·관련 검사·빌드 및 커밋.
