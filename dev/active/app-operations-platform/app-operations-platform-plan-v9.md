# 앱 운영 플랫폼 개발계획 v9 — 앱 종료 시 프로세스 정리

고정일: 2026-09-13. 사용자 요청에 따라 창을 닫아도 제어 서비스가 계속 실행되던 수명주기를 변경한다. v1–v8은 이력으로 보존하며 AI 요청 UX와 resume/clear 계약은 v8을 유지한다.

- 마지막 창 닫기와 앱 종료는 macOS를 포함해 제어 서비스·AI CLI·실행 중인 작업을 함께 정리한다. 데모/실제 모드 모두 적용한다.
- 기동·재시작 도중 종료해도 뒤늦게 제어 서비스가 남지 않도록 기다린 뒤 중지한다. HTTP 종료뿐 아니라 실제 프로세스 종료를 확인한다.
- 기존 작업 취소와 프로세스 그룹 정리를 재사용하고 중지 표식으로 서비스의 자동 재기동을 막는다. 다른 앱의 프로세스는 종료하지 않는다.
- 화면 안내·사용법·검증 기록을 새 동작과 일치시킨다. 요청하지 않은 커밋·푸시는 수행하지 않는다.

완료 조건: 수정 전 재현, 창 닫기·앱 종료·기동 중 닫기의 실제 Electron 검사, AI CLI와 자식 프로세스·제어 서비스 PID·포트 종료 확인, 관련 회귀 검사·타입·빌드 통과. 강제 종료(SIGKILL)·전원 차단은 정상 종료 이벤트를 실행할 수 없어 이 계약에 포함하지 않는다.
