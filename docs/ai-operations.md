# AI 요청과 대화

**AI 요청**과 **AI 대화**는 현재 화면·선택 대상을 전달해 기존 채팅을 연다. 버튼 클릭만으로 AI를 실행하거나 고정 작업을 사용자 발언으로 저장하지 않는다. 사용자가 채팅에 작성한 내용을 **전송**하거나 Enter를 눌러야 실행한다. 프로젝트 등록·화면 이동·새로고침·재시작만으로도 실행하지 않는다.

버튼에 들어 있던 계정 설정·스토어 등록 등의 기본 지시는 제거했다. 서버는 내용 없는 요청을 거부한다. 새로운 작업 후보나 요청 흐름은 추가하지 않았으며, 요청 방식의 재설계는 사용자가 별도로 정한다.

대상 프로젝트는 화면에서 선택한 항목을 그대로 사용한다. 대상이 없는 화면은 전체 운영 대화로 연결된다. 전송할 때의 화면·선택 대상이 전달되므로 이전 화면에서 고른 계정이 다른 화면의 요청에 남지 않는다. AI 운영 화면에서는 대화 대상을 선택할 수 있다. 여러 프로젝트 중 하나를 임의로 골라 스토어에 쓰지 않는다.

## Codex / OpenCode CLI

설치된 `codex`와 `opencode`를 탐지하며 API 키 입력 폼을 추가하지 않는다. 각 CLI에 이미 설정한 로그인·모델을 재사용한다. AI 선택의 자동 모드는 **제공자 선택**이며 자동 작업 시작을 의미하지 않는다.

프로젝트별 대화와 전체 운영 대화는 별도로 보관한다. 첫 요청에서 받은 실제 CLI 세션 ID를 저장하며 후속 요청은 `codex exec resume <id>` 또는 `opencode run --session <id>`로 이어진다. 화면을 닫거나 앱을 재시작해도 같은 ID를 사용한다. 진행 도중 종료됐으면 다음 사용자 요청을 기다린다.

클리어 전에는 제공자를 바꾸지 않는다. 세션 ID를 잃거나 resume에 실패해도 조용히 새 대화를 만들지 않는다. **클리어**는 현재 실행을 정리한 뒤 대화와 세션 연결을 비운다. 다음 요청에서 새 세션을 시작하며 제공자를 다시 선택할 수 있다. 클리어 자체는 AI를 실행하지 않는다. 준비한 문구·이미지와 외부 변경 이력은 보존하며, CLI 자체가 보관하는 과거 세션 파일을 삭제하는 기능은 아니다.

## 자료 준비와 계정 연결

AI는 제한된 프로젝트 자료와 기존 계정·앱 매핑·작업 결과를 읽는다. 문구에는 분석 근거를 남긴다. CLI에 이미지 생성 도구가 설정되어 있으면 그 출력을 가져오고, 없으면 정적 SVG를 작성해 실제 PNG로 렌더링할 수 있다. 생성한 홍보 그림을 실제 게임 스크린샷으로 표시하지 않는다.

스토어 API 변경은 기존 큐·정책·중복 방지를 통과한다. 현재 문구 반영, 준비한 이미지 업로드와 앱 확인 근거가 있어야 등록 완료로 표시한다. 신규 앱 생성이 API로 지원되지 않으면 CLI에 설정된 브라우저 도구로 공식 콘솔 절차를 진행해야 한다. 브라우저 도구 부재, 로그인·MFA·CAPTCHA, 계약 동의나 자료에서 알 수 없는 필수 사실은 대화에서 정확히 요청한다.

원본 프로젝트 수정·빌드, 심사 제출·실제 공개, 광고비 집행, SNS 발송은 이번 AI 실행 범위에 포함하지 않는다. [2차 성장 운영 기획](../dev/active/ai-growth-operations/ai-growth-operations-plan-v2.md)은 별도 문서이며 주기적 실험·고객응대 기능은 아직 구현하지 않았다.
